# Documentación de MarkovLab

Esta carpeta reúne las referencias del proyecto en tres categorías amplias. Empiece por la categoría que responda a su pregunta y consulte su README para encontrar los documentos disponibles.

- [Contexto](contexto/README.md): problema, alcance, actores y requisitos.
- [Técnica](tecnica/README.md): arquitectura, estructura, conexiones y decisiones técnicas.
- [Datos](datos/README.md): futuros conjuntos CSV, diccionarios de datos, procedencia y reproducibilidad.

Para buscar información nueva, elija primero la categoría por tema; evite crear subcategorías para cada documento. Si un tema cruza categorías, enlácelo desde la guía pertinente en lugar de duplicarlo.
