# Datos semilla

Este directorio reserva un lugar para datos de ejemplo reproducibles destinados a desarrollo o pruebas, cuando se defina el esquema PostgreSQL.

## Contenido previsto

Podrán incorporarse conjuntos de datos de muestra y notas que expliquen su origen, propósito y forma de uso, siempre sin información sensible.

## Límites

Hoy no hay datos semilla ni procedimientos de carga. No se deben guardar credenciales, datos reales privados ni configuración de Supabase aquí. Las semillas no sustituyen las migraciones del esquema; el acceso de negocio a los datos corresponderá a la API Julia, nunca directamente al frontend.
