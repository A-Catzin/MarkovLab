# Documentación de datos

Este directorio reserva un lugar para explicar las decisiones futuras de persistencia y facilitar su revisión.

## Contenido previsto

Podrán añadirse descripciones del modelo de datos, convenciones y guías de operación de PostgreSQL administrado por Supabase, una vez definidas. Los requisitos generales permanecen en [`SRS.md`](../../SRS.md).

## Límites

Este espacio no contiene esquemas SQL, migraciones, semillas, configuración ejecutable ni credenciales. La documentación no sustituye la implementación: la API Julia concentrará el acceso y las reglas de negocio, y el frontend no se conectará directamente a la base de datos.
