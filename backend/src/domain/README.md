# Dominio

Responsabilidad futura: definir modelos y reglas financieras independientes de servicios externos.

Contenido permitido: tipos, invariantes y cálculos puros con pruebas reproducibles. Límite: no recibir HTTP, consultar proveedores ni persistir datos; esas operaciones pertenecen a otras capas. Aún no hay lógica de negocio.
