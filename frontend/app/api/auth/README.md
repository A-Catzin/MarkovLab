# `auth` API Routes

## Overview
Intermediate routing directory grouping Auth.js authentication endpoints under the Next.js App Router.

## Subdirectories & Boundaries
- `[...nextauth]`: [`./[...nextauth]/README.md`](./[...nextauth]/README.md) - NextAuth catch-all route handler (`GET` and `POST`) delegating to `authOptions` from `@/lib/auth`.
